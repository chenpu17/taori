# P3-3 本地模板市场提案

## 背景

现有 Prompt Template / Workflow Recipe 虽然已经可用，但入口分散、发现成本高：用户知道“能创建”，却不容易在聊天现场快速挑到合适模板。P3-3 的目标是把这些资产收成一个可浏览、可预览、可立即套用的本地模板市场。

## 设计

### 1. 只做本地聚合，不引入新存储

- 数据仍来自现有：
  - Prompt Templates
  - Workflow Recipes
  - 前端内置工作流模板
- 模板市场不新增表，也不复制模板内容。
- 这意味着资产真相仍在既有 Prompt / Recipe 数据模型里，市场只负责聚合与发现。

### 2. 聊天现场优先

- 入口放在聊天头部，替换原先较弱的“模板”按钮。
- 用户在市场内完成：
  - 搜索
  - 按来源筛选
  - 右侧预览
  - 一键套用
- 若模板带变量，则继续复用既有变量填写弹窗；若是 Workflow Recipe，则继续复用 Sidecar `apply-preview` 路径生成最终 prompt。

### 3. 预览优先于点击

- 列表项 hover / focus 时更新右侧预览，点击仍保持原来“立即套用”的快速路径。
- 这样既不破坏已有用户肌肉记忆，也补上“先看再用”的发现体验。

## 取舍

- 本轮不做远程分发、评分、下载量或社区同步；这些属于未来模板分发层。
- 先把“本地模板资产能被看见、被理解、被快速复用”做好，再决定是否要继续演进成真正的模板生态。
