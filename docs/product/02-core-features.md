# 02 · 核心功能

> MVP 真实核心一句话：
> **配好多个模型后，用户在一个聊天窗口里能稳定完成任务；失败时能换模型；需要多视角时能拉起圆桌；任何时刻都看得清成本。**
>
> 配置中心是**基础设施**，不是产品主角；服务于上述工作流即可。

## 功能 1 — 多模型配置中心（轻量版）

**MVP 范围（克制）：**
- 支持聊天模型、图像模型两类
- 支持默认模型、备用模型（含降级顺序）
- API Key 通过 OS Keychain 本地存储
- OpenRouter 一键导入（最大化"配好就能用"）
- 一键可用性检测
- **每个模型必填或自动获取单价**（这是成本透明的前提）

**MVP 不做（移到第二阶段）：**
- 完整能力卡（擅长/不擅长/稳定性评分等）
- 配置模板市场
- 健康状态面板

## 功能 2 — 聊天中无缝调用其他模型

> 失败兜底专题独立成章，详见 [04-failure-resilience.md](./04-failure-resilience.md)。本节聚焦"跨模型调用"交互。

**典型场景：**
> 用户在对话中说："帮我画一张赛博朋克风格的咖啡店海报。"

**交互流程：**

1. LLM 识别意图为"图像生成"
2. 弹出轻量选择器：

```
┌─────────────────────────────┐
│ 选择图像模型                  │
│ ● 模型 A    （推荐 · 适合海报）│
│ ○ 模型 B    （速度快）        │
│ ○ 模型 C    （价格低）        │
│ ─────────────                │
│ 记住选择：                    │
│   ○ 仅本次                   │
│   ○ 当前会话                  │
│   ○ 以后类似图像任务默认       │
│   ○ 总是先询问我              │
└─────────────────────────────┘
```

3. 执行调用，结果直接嵌入对话流

## 功能 4 — 成本透明（产品主线）⭐

详见 [03-cost-transparency.md](./03-cost-transparency.md)。

## 功能 5 — 桌面专属能力（至少一个，证明"桌面端不是外壳"）

MVP 选择**最低成本 + 最高价值**的一个：

- ✅ **拖入本地文件/图片到聊天**（默认 MVP 包含）
  - 文件直接送入对应模型（图像 / 文档解析 / 多模态）
  - 用户感知最强："这是个本地工具"
- 🟡 全局快捷键呼出（次优先）
- 🟡 剪贴板内容快捷发送（次优先）
- ❌ 文件批量处理 / 编辑器集成 → 第二阶段

## 第二阶段扩展功能

> MVP 不做，但已纳入产品蓝图。Agent 与工具的完整路线图见 [09 · Agent 与工具体系](./09-agent-and-tools.md)。

### A. 模型对比 / Benchmark Lab
同一 prompt 一键发给多个模型，横向并排展示**结果 + 耗时 + 成本**。圆桌的轻量版。

### B. 智能模型路由
用户不手动选模型，而是选**策略**：优先质量 / 优先速度 / 优先便宜 / 优先稳定 / 优先隐私 / 总是询问 / 自动选择但失败时询问。

### C. 模型降级与备援（模型组）
```
默认图像生成组：
  首选：模型 A
  备用：模型 B
  低成本备用：模型 C
```

### D. 任务型会话
不同会话类型对应不同 UI 和默认模型组合：普通聊天 / 多模型讨论 / 图像创作 / 视频创作 / 文档分析 / 代码协作 / 研究报告 / 自动化工作流。

### E. Pipeline 工作流编排
保存常用组合：
> 写文案 (GPT) → 翻译 (DeepSeek) → 配图 (SD) → 配音 (ElevenLabs)

用户看到的是**任务进度**，不是一堆独立调用。

### F. 成本与用量看板（高级）
每模型本月消耗 / 哪个会话最贵 / 月度预算告警 / 智能省钱建议。

### G. 模型健康状态面板
正常 / 慢 / 失败率高 / 额度不足 / Key 异常 / 不可用。

### H. 知识库 / 长期记忆（RAG）
会话级 / 全局级挂载文档，配合 Embedding 模型。

### I. 偏好学习
逐渐学习用户偏好，**每次保存都需用户确认，杜绝静默改变行为**。

### J. 提示词 / 圆桌模板市场
社区分享 Prompt 模板 + 圆桌配置模板。

### K. 本地模型支持
通过 Ollama 等接入本地模型 —— 对隐私敏感用户是杀手锏。

### L. 桌面端深度能力
本地文件批量处理 / 剪贴板监听 / 全局快捷键 / 编辑器集成。
