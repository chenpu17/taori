# 03 · 成本透明专题（产品主线）⭐

## 设计哲学

> **成本不是数字，是"安全感"。**
> BYOK 用户花的是自己的钱，他们要的不是"省钱功能"，而是 **"我永远清楚自己在花什么"**。

**关键克制原则：避免"焦虑型 UI"。**
成本要有存在感，但不能让用户感觉每说一句话都在看计价器。**默认轻量、详情按需展开。**

## 差异化机会

竞品通病：ChatGPT/Claude 是包月看不到 per-call、OpenRouter Web 只能事后看账单、LangChain Studio 是开发者工具。
**我们把成本变成 UI 的一等公民，像电量、流量一样始终在视野里。**

## 成本可见性"四个时刻"

| 时刻 | 展示 | 目的 |
|---|---|---|
| 调用前 | 预估区间 + 价位徽章 | 知情决策 |
| 调用中 | 轻量小标签（默认）；展开看 token + 跳动金额 | 流式过程可控但不焦虑 |
| 调用后 | 实际成本 + 与预估对比 | 透明追溯 |
| 聚合视图 | 会话/今日/本月/按功能 | 复盘判断 |

## 关键交互设计

### 1. 模型选择器·价位徽章
```
○ GPT-4o       💰💰💰  ~$0.005/次
● Haiku        💰      ~$0.0003/次  ← 推荐
○ DALL·E 3     💰💰    $0.04/张
○ Sora         💰💰💰💰💰  ⚠️ 高成本
```

### 2. 发送按钮·预估提示
```
[发送] · 预计 ~$0.003（基于 1.2k tokens）

[启动圆桌] · 3 模型 × 2 轮 + 总结 = 7 次 · ~$0.08–0.15
```

### 3. 流式过程·轻量显示（避免焦虑）
- **默认：仅在右下角显示一个低饱和的小标签**（如"生成中 · ~$0.00X"），不实时跳动数字
- **展开后才看明细**：用户点击可看到 token 实时计数 + 跳动金额
- 重要：聊天是高频操作，**默认 UI 不能让用户每发一句话都盯着计价器**

### 4. 高成本前置确认（柔性，不打扰）
- **默认阈值 > $0.20** 触发确认
- 用户可在设置中调整阈值，或设为"无限制"
- **视频生成、图像生成单独开关**，默认开启（即使低于阈值也确认一次）
- 圆桌包含昂贵模型时同样触发
- **必含"不再提醒"选项**：可对此模型/当前会话/永久关闭确认，避免打断创作者工作流

```
⚠️ 此次调用预计 ~$0.45（视频生成 5 秒）
   [继续]  [改用低成本模型先出草稿]  [取消]
   ☐ 此模型不再提醒   ☐ 本会话不再提醒
```

### 5. 会话级成本仪表盘（常驻）
对话视图角落显示：
```
本会话: $0.087 (12次)  | 今日: $1.42  | 本月: $18.30
```

### 6. "未知/无 API 费用"诚实表达
- 本地模型 / Ollama → `本地 · 无 API 费用`（不写"免费"，因为仍有电费/硬件/时间成本）
- 未配单价 → `成本未知` 并提示补充
- 视频等按结果计费 → `预估 ~$X，实际以服务商账单为准`

### 7. 圆桌总结附带成本结构
总结报告里强制带一行明细，让用户对"开圆桌的代价"形成直觉。

## 货币显示

- **默认 USD**，设置中可切 **CNY**（按实时汇率近似换算）
- 历史记录保存原始 USD 成本，切换显示时即时换算

## 成本数据模型（每次调用必记）

| 字段 | 用途 |
|---|---|
| 模型 ID + provider | 归因 |
| 输入 / 输出 token 数 | 计算 |
| 单价快照（调用时刻） | 防价格变动失真 |
| 估算金额 / 实际金额 | 对比追溯 |
| 所属会话 / 任务 / 功能 | 多维聚合 |
| 时间戳 | 时段聚合 |
| 是否成功 | 失败也可能扣费，要诚实展示 |

> 完整 SQLite Schema 见 [架构文档 04-data-and-storage.md](../architecture/04-data-and-storage.md)。

## MVP 成本能力分级

> **术语对齐：** 本项目"MVP"覆盖 **M1 内测版 + M2 核心 MVP**；其中 M1 验证最小闭环（配置 → 聊天 → 看成本），M2 才补齐失败兜底与高成本保护。详见 [07-mvp-roadmap.md](./07-mvp-roadmap.md)。

| 等级 | 内容 | 引入版本 |
|---|---|---|
| L1 | 调用后展示实际成本（消息级徽章） | **M1** |
| L2 | 模型选择器价位徽章 + 发送前预估 + 状态栏会话/今日累计 | **M1** |
| L3 | 流式轻量显示 + 高成本前置确认（图像/视频独立开关，可"对此模型不再提醒"） | **M2** |
| L4 | 会话级仪表盘 + 历史聚合 + 按模型/feature 拆分 | **M2** |
| L5 | 智能省钱提示 + 跨模型对比建议 | 第二阶段 |
| L6 | 预算上限 + 告警 + 自动拦截 | 第二阶段 |
