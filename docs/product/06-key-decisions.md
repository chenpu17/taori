# 06 · 关键决策（已确认）

本文件汇总所有已确认的产品级决策。技术决策见 [架构文档 02-tech-stack.md](../architecture/02-tech-stack.md)。

## 1. 圆桌讨论：角色由系统自动生成 + 双模式 ⭐

**原则：用户只抛话题，系统自动安排"专家视角"，用户不做配置。**

- 用户只输入"话题"，系统根据话题语义 + 已配置可用模型，**自动**选模型 + 生成视角提示词
- **快速模式（默认）**：一轮独立观点 + 自动总结
- **深度模式**：盲审 → 互见反驳 → 总结
- 启动前展示**预估调用次数与成本区间**
- 总结固定输出：共识 / 分歧 / 风险 / 推荐决策 / 下一步行动
- 可选高级模式手动调整，但 MVP 默认不暴露

详见 [05-roundtable.md](./05-roundtable.md)。

## 2. 失败降级：默认关闭，渐进式降权

- 失败时弹出决策型提示，不静默切换
- 用户可在偏好中开启"自动降级"
- 渐进式策略：单次失败 → 提示；24h≥3 次 → 降权（UI 下移）；24h≥5 次 → 临时禁用 24h
- 内容审核失败不计入异常计数；用户手动重试成功立即清除异常
- 系统不擅自拉黑模型，所有降权对用户透明可见

详见 [04-failure-resilience.md](./04-failure-resilience.md)。

## 3. 成本：MVP L1–L4 全部展示，不做硬控制

- 调用前/中/后全程展示成本
- **高成本前置确认默认阈值 $0.20**，用户可调或关闭
- **视频生成、图像生成独立开关**（默认开启，即使低于阈值也确认）
- **必含"不再提醒"选项**（按模型/会话/永久）
- 货币默认 USD，可切 CNY
- 第二阶段再加预算上限与告警

详见 [03-cost-transparency.md](./03-cost-transparency.md)。

## 4. 记忆：UI 三级

**仅本次 / 当前会话 / 以后默认**。内部可有更细粒度但不暴露。

## 5. 本地数据加密：非 P0

- MVP：API Key 用 OS Keychain，对话历史明文 SQLite
- 第二阶段加完整加密

详见 [架构文档 05-security.md](../architecture/05-security.md)。

## 6. 桌面专属能力 MVP 必含

**拖入本地文件到聊天**（最低成本 + 最高价值）

- 图片 → 自动切到支持视觉的模型
- PDF/文本 → MVP 简单方案（直接读文本送入）
- 其他类型 → 提示尚不支持

## 7. Provider 接入策略

- **OpenRouter 优先**（一键导入即可获得海量模型）
- 保留直连各家 Provider 的能力（OpenAI / Anthropic / Ollama 等）
- 第二阶段开放更多本地推理后端（Ollama / LM Studio）
