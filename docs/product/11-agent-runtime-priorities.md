# 11 · Agent 运行时前三优先级

Status: draft
Date: 2026-05-03

## 1. 背景

Taori 的定位不是通用自治 Agent，而是多模型工作编排助手。参考 OpenClaw 后，当前最该补强的是“可控、可解释、可连续”的运行时能力，而不是自动替用户决定基础对话模型。

## 2. 前三关键特性

| 优先级 | 特性 | 用户价值 | 产品边界 |
|---|---|---|---|
| P1 | 会话画像 | 用户随时知道当前会话使用的模型、Persona、工具、上下文来源和成本 | 展示与确认，不自动切模型 |
| P2 | 会话级工具策略 | 同一个会话可临时关闭网页、图片等工具，不影响全局配置 | 工具可控，默认继承全局 |
| P3 | 上下文透明 | 每次回答显示实际注入的 Persona、附件、工具策略等来源 | 先展示来源，不做隐式长期记忆 |

## 3. 模块映射

| 模块 | 改动 |
|---|---|
| `packages/shared` | 新增会话画像、有效工具、上下文快照 schema |
| `apps/sidecar` | `/v1/conversations/:id/profile` 输出会话画像；工具调用和 LLM 工具注入尊重会话级策略；`/v1/chat` 追加 `context_snapshot` annotation |
| `apps/web` | 聊天头部展示会话画像；提供当前会话工具开关；assistant 消息展示上下文来源 |
| `docs/modules/inventory.md` | 记录跨模块合同变化 |

## 4. 验证设计

- Sidecar：验证会话工具策略会阻止 `/v1/tools/invoke`，且 profile 返回有效工具状态。
- Web UI：用 Playwright 从聊天页创建会话、关闭本会话网页工具、发送多轮消息，观察画像条和上下文来源卡片。
- 回归：跑 sidecar 相关测试和新增/相关 e2e，确认全局工具开关、图像工具、成本记录不被破坏。
