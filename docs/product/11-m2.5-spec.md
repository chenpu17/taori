> 状态：✅ 已实现（v0.7）

M2.5 是 M2（Capability Bus）→ M3（Roundtable）之间的过渡里程碑，目的是把"模型管理"从一个简陋的对话框升级为产品的核心页面，并补齐价格、Ark MaaS、能力路由这几个用户在 M2 验收时反馈的痛点。

## 2. 详细规格

### 2.1 F-MC · Model Center

**入口**：顶部工具栏 🧬 按钮 → 弹出 `<ModelCenter>` overlay。

**信息架构**：
- 顶部 Provider Chips：每个已配置 Provider 一个 chip，点击可删除；末尾"➕ 添加 Provider"按 nav 回 Onboarding。
- 能力 Tab：`chat / multimodal / image / video / audio / embedding`（顺序固定），每个 tab 显示该能力下所有模型。
- Tab 操作：`🔄 同步价格` / `➕ 导入模型`（打开 ImportDrawer）。
- 矩阵表：列 = `启用 / 模型 / Provider / 上下文 / 输入价 / 输出价 / 别名 / 操作`。

**ImportDrawer**：
1. 调 `GET /v1/providers/:id/discover` 拉取该 Provider 的可用模型。
2. 按当前 tab 能力过滤（`chat` 同时纳入 `multimodal`）。
3. 已存在的 `(provider_id, model_name)` 自动屏蔽。
4. 用户多选 → 逐个 `POST /v1/models` 创建。

**验收**：
- A1. 用户从 ModelCenter 一键进入 Onboarding 添加 Provider，回来即看到新 chip。
- A2. ImportDrawer 正确读取并过滤 OpenRouter / Ark 模型；不重复导入。
- A3. 同步价格后矩阵显示新价格；折叠面板显示 `new` / `price_changed` 行级 diff。
- A4. 关闭 ModelCenter 后侧边栏 / Settings 不再出现旧的模型管理 UI。

### 2.2 F-PR · Price Catalog

**模块**：`apps/sidecar/src/catalog/index.ts`（`syncCatalog()`）。

**触发点**：
1. 启动时 async 调用一次（不阻塞 UI）。
2. 每 24h 周期。
3. 用户点击"🔄 同步价格"。
4. `POST /v1/catalog/sync`。

**逻辑**：
- 遍历 `provider.enabled = true` 且 `type ∈ {openrouter, volcengine_ark}` 的 Provider。
- 调用各自的 `discover()` 取归一化模型列表。
- 与 DB 中现有 `(provider_id, model_name)` 比对：
  - 不存在 → 输出 `change: 'new'`（仅 diff，不自动创建用户模型）。
  - 存在且价格字段变化 → 输出 `change: 'price_changed'` + 调用 `ModelsRepo.patchPricing()`。
  - 不论是否变化，价格相关字段被 PATCH 时**始终更新 `price_synced_at`**（用作"上次同步时间"）。
- 单个 Provider 失败不阻断其他 Provider；失败信息收集到 `errors[]`。

**响应 schema**：
```ts
{
  ok: true,
  synced_at: number,
  total_providers: number,
  total_models: number,
  diffs: CatalogModelDiff[],
  errors: { provider_id: string, error: string }[],
}
```

**验收**：
- B1. OR 真实环境调用 `/v1/catalog/sync` 返回 376+ 模型 diff。
- B2. 用 bad-key Provider + good-key Provider 同时存在时，bad 报 `errors[]`，good 仍写入 diff。
- B3. 用户字段（如 `display_name` 别名）不被价格同步覆盖。

### 2.3 F-CR · Capability Routing v2

- **强意图 fast-path**：`detectImageIntent` 正则放宽匹配"帮我/请你/给我画/画一张/sketch/render/plot"。命中即直接进 image picker，**忽略本轮 LLM**。
- **LLM 兜底**：当 fast-path 未命中但用户已配置至少一个 image 模型时，向 chat completion 请求注入 `image_generate` 工具描述；模型可在对话流自然调用。
- **互斥**：fast-path 命中 → 不附 tool；未命中 → 附 tool；保证不双触发。
- **静默降级**：当用户没有任何 image 模型时，LLM 不附该 tool，避免误导式工具不可用错误。

**验收**：
- C1. "帮我画一张机器人的图像" → fast-path 命中 → 出图。
- C2. "你能给这个故事配图吗？" → LLM 自行决定调用 `image_generate`。
- C3. 没装 image 模型时，"帮我画…" 给出友好提示而不是工具失败。

### 2.4 F-CB · Cost Badge

- 每条 assistant 气泡右下角注入 `<CostBadge>`，显示 `$0.0042 · 1.2k tok`。
- Hover 展开 in/out tokens、provider/model 名、`actual_usd`（若 Provider 给出）。
- 底部状态栏继续显示"今日 / 本月"聚合（已有 `/v1/costs/*`）。

**验收**：
- D1. 一次 OR 调用结束后，CostBadge 出现且金额非 0。
- D2. Provider 返回 `actual_usd` 时优先使用该值，否则回退到本地估算。

### 2.5 F-AR · Volcengine Ark Adapter

**适配器**：`apps/sidecar/src/providers/volcengine_ark.ts`（新增）。

**模型来源**：内置 `ARK_FAMILIES` 表（doubao 1.5 / 1.5-vision / wan / seedance），每个家族预置：
- `capability` ∈ {chat, multimodal, image, video}
- `modalities` ∈ {text, image, video}
- 默认价格（CNY → USD 转换，常量 7.0 ≈ 当前汇率，注明"价格估算"）
- `context_length`、`supports_vision`、`supports_tools`

**Discovery**：直接返回 ARK_FAMILIES（不主动拉云端 endpoint 列表，因为 Ark endpoint 名称是用户自定义的；用户在 ModelCenter 导入后再编辑别名映射）。

**Sync**：在 catalog 同步循环中作为 first-class provider；价格随 ARK_FAMILIES 升级而升级。

**验收**：
- E1. 在 Onboarding/Add Provider 中可选 `volcengine_ark` 预设。
- E2. 创建 Ark Provider 后，`/v1/providers/:id/discover` 返回 doubao + wan + seedance 模型，覆盖 chat/multimodal/image/video。
- E3. 一次 image_generate 调用可路由到 wan/seedance 模型（M3 时具体打通；M2.5 仅保证模型注册可见）。

## 3. 验收脚本（用户手动测试 Playbook）

> 前置：用户已配置至少一个 OpenRouter Provider（含真实 API Key）。

| 步骤 | 操作 | 期望 |
|---|---|---|
| 1 | 点工具栏 🧬 | 弹出 ModelCenter，显示已有 Provider chips |
| 2 | 点"+ 添加 Provider" | 跳回 Onboarding，"火山方舟"在 preset 中 |
| 3 | 选 `volcengine_ark` 走完 onboarding | 回到 ModelCenter，看到新 Ark chip |
| 4 | 切到 image tab → "+ 导入模型"（Ark） | Drawer 列出 wan / seedance 等图像模型 |

| 6 | 点"🔄 同步价格" | 顶部出现"X new, Y price_changed"，可展开看 diff |
| 7 | 关闭 ModelCenter，进对话区，输入"帮我画一张机器人的图像" | 触发 image fast-path，出图 |
| 8 | 一次普通 chat 完成 | assistant 气泡右下出现 CostBadge `$… · …tok` |
| 9 | 进 Settings | 仅看到 AutoFallback / Reopen Onboarding / DangerZone |
