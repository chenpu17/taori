# 13 · MCP / 复杂价格 / 圆桌工具首版

Status: implemented v0.9 draft  
Date: 2026-05-04

## 目标

围绕 Taori 的“多模型工作编排助手”定位，本批补齐三项高优先级能力：

1. **MCP 本地 stdio 工具接入首版**：用户可在控制中心添加本地 MCP Server，刷新工具清单，并让支持 tools 的模型使用这些工具。
2. **复杂价格 `pricing_meta` 首版**：模型可记录分辨率、质量、时长等分级价格，避免图像/视频/音频模型只剩单一价格字段。
3. **圆桌参与者工具调用首版**：圆桌参与者不再只是“纯聊天模型”，可在发言过程中调用 web/MCP 工具，工具痕迹在前端列内可见。

## 用户旅程

- 用户在“控制中心 → 工具能力”添加本地 MCP Server，填写 command / args，点击“添加并刷新”后看到健康状态、工具数量和 MCP 工具卡片。
- 用户在“模型中心 → 编辑模型”填写 `pricing_meta` JSON，用于记录复杂价格规则；基础成本估算仍使用已有字段，避免突然改变扣费显示口径。
- 用户发起圆桌时，如果参与模型支持 tools，圆桌每位参与者可使用内置 web 工具或 MCP 工具；前端在对应参与者列展示“调用 / 完成 / 失败”的工具痕迹。

## 首版边界

- MCP 仅支持本地 `stdio`，不支持远程 MCP / HTTP transport / 工具市场。
- MCP Server 的 env 支持后端合同，但 Web 首版仅提供 command / args；敏感 env 的 UI 管理后续补。
- `pricing_meta` 只做持久化、展示和手动编辑；成本计算仍以基础价格字段为准。
- 圆桌工具痕迹首版保留在本次前端运行态；后续可落库为 roundtable tool event，纳入 Run Timeline。

## 不做

- 不做自动模型动态路由。
- 不让系统替用户自动选择基础对话模型。
- 不把 MCP 工具默认暴露给不支持 tools 的模型。
